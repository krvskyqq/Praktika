# Менеджер контактов с нечетким поиском

Учебная ознакомительная практика. Автор: Куровский Евгений Евгеньевич.

Приложение на Python, Tkinter и JSON: добавление, просмотр, редактирование и удаление контактов; поиск по имени, телефону и email с учетом опечаток и раскладки; история десяти запросов; импорт и экспорт JSON; резервное копирование. Дополнения: заметки, учебные категории и фильтр по категориям.

## Запуск

Готовые сборки Windows x64 и Linux x64 публикуются в Releases после успешных проверок. Windows: запустите `ContactManager.exe`. Linux: распакуйте архив и выполните `chmod +x ContactManager && ./ContactManager` в графической сессии. Linux-сборка предназначена для систем с glibc 2.35 и новее (Ubuntu 22.04+); нужен доступный графический сервер X11/XWayland. На обеих платформах установка Python для готовой сборки не требуется.

Из исходников: Python 3.12 с Tkinter, затем `python main.py`. На Ubuntu для исходников: `sudo apt install python3-tk`.

## Работа с контактами

- Вкладка «Новый контакт»: имя и телефон обязательны, email необязателен.
- «Все контакты»: фильтр категорий и сортировка кликом по заголовку.
- «Поиск»: введите имя, часть телефона или email. `Ltrfyfn` находит «Деканат». Процент обозначает сходство строк, а не вероятность правильного ответа. Порог включения — 0,3.
- Двойной щелчок или Ctrl+E открывает редактирование. Ctrl+N — создание, Ctrl+F — поиск, Delete в таблице — удаление с подтверждением, Escape — сброс поиска.
- Импорт принимает массив объектов JSON либо объект с массивом `contacts`. При некорректной записи весь импорт отменяется. Дубликаты по паре «имя + телефон» пропускаются.

Данные Windows: `%LOCALAPPDATA%/KurovskyContacts`; Linux: `$XDG_DATA_HOME/kurovsky-contacts` или `~/.local/share/kurovsky-contacts`. Копии сохраняются в `backups` внутри папки данных. Для восстановления при закрытой программе скопируйте нужный проверенный файл из `backups` вместо `contacts.json`. Копии автоматически не удаляются. JSON не зашифрован, резервные копии тоже содержат контакты. Одновременная работа нескольких экземпляров с одной базой не поддерживается.

Для отдельной базы: `python main.py --data-dir ./demo-data`. В репозитории нет реальных персональных контактов. `examples/demo.json` содержит вымышленные учебные записи для импорта.

## Проверка и сборка

```text
python -m unittest discover -v
python main.py --self-test --test-result result.txt
python -m pip install -r requirements-build.txt
python -m PyInstaller --clean --noconfirm --onefile --windowed --name ContactManager main.py
```

На Linux команды GUI-проверок в CI запускаются через `xvfb-run -a`. PyInstaller запускается отдельно на Windows и Linux. Готовая сборка тоже выполняет `--self-test --test-result result.txt`, проверяющий JSON, раскладку и создание интерфейса во временной базе. Успешный результат — `PASS`.

## Архитектура

`models.py` — Contact, Validator и нормализация телефона. `manager.py` — ContactManager, JSON, резервные копии и поиск SequenceMatcher. `gui.py` — интерфейс Tkinter с тремя вкладками. `main.py` — запуск и самопроверка. `test_manager.py` — автоматические тесты логики. `.github/workflows/build.yml` — проверки, сборки и публикация релиза.

При сохранении сначала создается резервная копия, затем JSON записывается во временный файл и заменяет основной через `os.replace`. Список в памяти обновляется после успешной записи. Это защищает от частичной записи; физическая потеря диска по-прежнему требует внешней резервной копии.
